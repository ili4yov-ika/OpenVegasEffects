Материалы для разработки; в сборку ничего отсюда не входит.

| Папка | Что в ней |
|-------|-----------|
| `VEGAS_Effects/` | Локальная копия эталонного приложения (VEGAS Effects 5.0.2): бинарники, нативные плагины `.hfpl` (`Plugins/`), переводы, карты окружения и декомпилированные исходники (`decompile-src/`). **В репозиторий не входит** (`SAMPLES/.gitignore`); положите сюда установленную копию, чтобы работали инструменты обратной разработки и тесты, которым нужны плагины эталона |
| [`vegfx_projects/`](vegfx_projects/) | Примеры проектов: `project_1` (2D-проект, сделанный в эталоне), `project_2` (3D-модели), `project_3` (куб с текстами на гранях, повороты по ключевым кадрам, эффекты на всём и два музыкальных файла с аудиоэффектами; его записывает тест `buildProject3`) |
| [`screenshots/`](screenshots/) | Скриншоты эталона с попиксельными разборами - источник истины для интерфейса |
| [`icons-from-VegesEffects/`](icons-from-VegesEffects/) | Иконки эталона, извлечённые из его ресурсов, с каталогом |

Медиафайлы примеров (`*.mp3`, `*.mp4`, `*.png`, `*.psd`) игнорируются
`vegfx_projects/.gitignore`, если не добавлены намеренно.
