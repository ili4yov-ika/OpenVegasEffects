# Скриншоты референса VEGAS Effects

Снимки интерфейса VEGAS Effects 5.0.2 и их пиксельные разборы. Каждому `N.png`
соответствует `N.md` с координатной раскладкой панелей, содержимым и цветовой
схемой. Используются как источник истины при переносе UI — см.
[`MARKDOWN/RE_VegasEffects.md`](../../MARKDOWN/RE_VegasEffects.md) §5.

## Указатель

| Файл | Разрешение | Что показано | Уникально на этом кадре |
|------|-----------|--------------|-------------------------|
| [`0.md`](0.md) | 1317×816 | Effects screen, эффект **Cartoon** на медиа-слое | Параметры эффекта в Controls: Preset, Edge, Fill |
| [`1.md`](1.md) | 1920×1080 | Панель **Controls** | — |
| [`2.md`](2.md) | 1920×1080 | Панель **Effects** + 3D-модель `octop.obj` | Полное дерево категорий эффектов (424 записи), слой `[Model]`, 3D-гизмо XYZ, вкладка `Layout` |
| [`3.md`](3.md) | 1920×1080 | Модальный диалог **Options** | Структура окна настроек |
| [`4.md`](4.md) | 1920×1080 | **Options**, вкладка **Export** | Параметры экспорта |
| [`5.md`](5.md) | 1920×1080 | **Controls** для `octop.obj`, World Transform | Трансформация 3D-объекта |
| [`crop_screenshot.md`](crop_screenshot.md) | 1280×720 (уменьшен ×2) | Edit screen, **анимация Point-слоя** | Ключевые кадры на дорожке Position (~60 шт.), `Value Graph`, 2D-гизмо, обе группы вкладок панелей |

## Замечания о разрешении

- `1.png`–`5.png` сняты нативно в 1920×1080.
- `0.png` — 1317×816. Координаты в разделах Controls/Timeline/Status Bar внутри
  `0.md` писались против сетки 1920×1080 и требуют пересчёта; поправка описана
  во врезке в начале файла.
- `crop_screenshot.png` уменьшен примерно вдвое: 1280×720 при исходных ~2560×1440.
  Все координаты в `crop_screenshot.md` даны в пикселях файла, для нативных
  умножайте на 2.

## Что из кадров ещё не перенесено

Сводка по [`crop_screenshot.md`](crop_screenshot.md) и [`2.md`](2.md):
transform-гизмо во вьюере, слои типов `Point` и `Model`, пространственная
интерполяция.

Ключевые кадры перенесены: ромбы на дорожке параметра, шесть временных типов
референса и кривая `Value Graph` на дорожке. Не перенесено из редактора кривых —
перетаскивание ключей и ручек мышью.
