## 🔑 Ключевые особенности этого скриншота

1. **Project Media** содержит **3 элемента**: два `ed.mp4` и один `octop.obj` (3D модель, выделена)
2. **Timeline** содержит **3 слоя**:
   - Layer 1: `1. octop.obj [Model]` (свёрнут)
   - Layer 2: `2. octop.obj [Model]` (выделен, свёрнут)
   - Layer 3: `3. ed.mp4 [Media]` (свёрнут)
3. **Controls панель** показывает свойства **octop.obj** (3D модель):
   - **Layer Properties**: Visible (☐), Dimension (2D), Blend (Normal), Motion Blur (☐), Parent (None), Include in Depth Map (☑), Depth Source Layer (None)
   - **World Transform**: Opacity (100%), Anchor Point (0,0,0), **Position (25.0, -169.0, 60.7)** — модель смещена за пределы кадра, Scale (100%), Orientation (0°,0°,0°), Rotation X/Y/Z (все 0°)
4. **3 круглых регулятора вращения** (Rotation X, Y, Z) — все в нейтральной позиции
5. **Viewer** показывает только размытое видео — 3D модель **не видна** в кадре (её Position 25, -169, 60.7 выводит её за пределы видимой области)
6. **Ring cursor** (белый круг) в центре Viewer — инструмент выбора/перемещения
7. **Header Controls** показывает путь: `ed.mp4 > octop.obj [00:03:12:16]`
8. **Dimension = 2D** для 3D модели (можно переключить на 3D для полноценного World Transform)
