## 🔑 Ключевые особенности этого скриншота

1. **Единственный кадр с раскрытым деревом эффектов.** Панель Effects (тип 4)
   показывает полный реестр категорий: `Favorites`, `Recents`, `360° Video`,
   `Animation`, `Audio`, `Behavior`, `Blurs` (раскрыта), `Channel`,
   `Color Correction`, `Color Grading`, `Depth`, `Distort`, `Generate`.
2. **Счётчик `424 item(s)`** в правом нижнем углу панели — это полное число
   записей реестра эффектов. Для сравнения: в `Plugins/` дистрибутива лежит
   **321** файл `.hfpl` (см.
   [`RE_VegasEffects_Distribution.md`](../../MARKDOWN/RE_VegasEffects_Distribution.md) §5.1),
   то есть в списке UI есть записи сверх набора родных плагинов — встроенные
   эффекты и/или узлы категорий.
3. **Содержимое категории `Blurs`**: `Angle Blur`, `Bilateral Blur`, `Blur`
   (под курсором, подсвечен), `Diffuse`, `Lens Blur`, `Motion Blur`,
   `Radial Blur`, `Zoom Blur` — 8 эффектов. У каждой записи справа звезда ☆
   (добавить в Favorites).
4. **3D-модель в проекте.** В Project Media третий элемент — `octop.obj`,
   подпись `321286 face(s)`, `0 transform group(s)`. Это подтверждает импорт
   геометрии через Assimp / FBX SDK из поставки.
5. **Слой типа Model.** В дереве таймлайна: `1. octop.obj [Model]` над
   `2. ed.mp4 [Media]` — единственный кадр, где виден тип слоя `[Model]`.
6. **3D-гизмо во вьюере** с тремя осями (красная X, зелёная Y, синяя Z) и
   квадратной ручкой привязки — в отличие от 2D-гизмо на `crop_screenshot.png`.
7. **Вкладка `Layout`** (тип 2055) видна в правой группе рядом с
   `Effects · Controls · Track` — подтверждает существование панели Layout.
8. **Футер Project Media**: `Folder` · `Composite Shot` · `Remove` · `3 item(s)`
   — набор действий над медиатекой.
9. **Медиа-параметры**: `ed.mp4`, 630×476 px, `00:03:12:16` @ 60 fps,
   stereo @ 48000 Hz; у второго элемента стоит звезда (избранное).
10. **Плейхед** на `00:00:23:18` при длительности `00:03:12:16`,
    масштаб вьюера `100.0%`, качество `Full`.
