Код приложения на C++17 / Qt 6, по папке на модуль. Раскладка модулей повторяет
высокоуровневую структуру эталона (см. [`MARKDOWN/ARCHITECTURE.md`](../MARKDOWN/ARCHITECTURE.md)).

| Папка | Что в ней |
|-------|-----------|
| [`main.cpp`](main.cpp) | Точка входа: командная строка в UTF-8, `QApplication`, переводы, `app::AppMain` |
| [`core/`](core/) | Базовые типы: `Identifier`, `Result`, `Version`, файловый журнал |
| [`app/`](app/) | Запуск (`AppMain`), папки пользовательских данных, настройки, переводы, шаблоны AV, умолчания проекта, папки плагинов, ассоциация файлов, проверка драйвера GPU |
| [`license/`](license/) | Интерфейс лицензии и свободный менеджер, который всегда сообщает о действующей лицензии |
| [`composition/`](composition/) | Модель: композиции, слои, клипы, эффекты, ключевые кадры, маски, стили текста, переходы, Behaviors и их симуляция, трекинг движения |
| [`project/`](project/) | Чтение и запись проектов `.vegfx` и композиций `.vegfxcs` в формате эталона, слияние проектов, пресеты эффектов (`.hfpr`) |
| [`media/`](media/) | Импорт и проба медиа, libVLC (`VlcBackend`, `Vlc4Adapter`), декодирование видео, микшер реального времени (`AudioPlayer`), запись закадрового голоса, волновые формы, приведённый звук, прокси, кэш декодированных кадров |
| [`plugin/`](plugin/) | Реестр плагинов и хост нативных модулей `.hfpl` (`NativeEffectRender`, `NativePlugin`): 2D-эффекты, переходы, звук, Behaviors, Geometry, собственный интерфейс во вьювере |
| [`model3d/`](model3d/) | Чтение 3D-моделей (OBJ, FBX, glTF, 3DS, LWO, Alembic), меши и 3D-рендерер |
| [`render/`](render/) | Рендеринг кадров (`RenderManager`), текст, геометрия слоёв, экспорт и его пресеты, кодирование видео и звука через FFmpeg, пререндеры, дисковый кэш кадров |
| [`cache/`](cache/) | База данных кэша медиа на SQLite |
| [`ui/`](ui/) | Главное окно, панели (Timeline, Viewer, Controls, Layer, Layout, Media, Text, Effects, Export, ...), диалоги и оверлеи вьювера |

Формы Qt Designer, которые загружают эти классы, лежат в [`ui/`](../ui/) в корне репозитория.
